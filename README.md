<h2>Project Overview</h2>
<p>
  Este README também está disponível em <a href="./README.pt-br.md">Português</a>.
</p>
<p>
  This project is a responsive product showcase website built with <strong>LESS</strong>.
  It demonstrates the use of variables, mixins, color maps, media queries, and automated compilation with LESS plugins.
  The layout features a sticky header, a responsive product grid, and interactive buttons.
</p>
<p>
  🔗 Live Demo: <a href="https://product-shop-layout-less.vercel.app/" target="_blank">View on Vercel</a>
</p>
<h2>Technologies Used</h2>
<ul>
  <li>HTML5</li>
  <li>CSS3 / LESS</li>
  <li>LESS Watch Compiler</li>
  <li>LESS Plugins</li>
  <li>Responsive Design</li>
  <li>Grid Layout</li>
  <li>Hover Effects</li>
</ul>
<h2>How to Run</h2>
<ol>
  <li>Clone the repository.</li>
  <li>Install dependencies with <code>npm install</code>.</li>
  <li>Run the LESS compiler to watch and build CSS:</li>
  <pre><code>npm run dev</code></pre>
  <li>Open <code>index.html</code> in your browser to view the product page.</li>
</ol>
<h2>Features</h2>
<ul>
  <li>Sticky header with navigation</li>
  <li>Responsive product grid using CSS Grid</li>
  <li>Reusable LESS variables, mixins, and color maps</li>
  <li>Interactive buttons with hover effects</li>
  <li>Placeholder images for easy customization</li>
</ul>
<h2>Additional Notes</h2>
<p>
  This project is intended for practicing <strong>LESS</strong> features and responsive design concepts.
  The layout adapts to desktop, tablet, and mobile screen sizes automatically.
</p>
