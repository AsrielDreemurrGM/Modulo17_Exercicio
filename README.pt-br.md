<h2>Visão Geral do Projeto</h2>
<p>
  This README is also available in <a href="./README.md">English</a>.
</p>
<p>
  Este projeto é um site responsivo de exibição de produtos, construído com <strong>LESS</strong>.
  Demonstra o uso de variáveis, mixins, mapas de colors, media queries e compilação automatizada com plugins do LESS.
  O layout conta com um cabeçalho fixo (sticky), uma grade de produtos responsiva e botões interativos.
</p>
<p>
  🔗 Demonstração Online: <a href="https://product-shop-layout-less.vercel.app/" target="_blank" rel="noopener noreferrer">Visualizar no Vercel</a>
</p>
<h2>Tecnologias Utilizadas</h2>
<ul>
  <li>HTML5</li>
  <li>CSS3 / LESS</li>
  <li>LESS Watch Compiler</li>
  <li>Plugins do LESS</li>
  <li>Design Responsivo</li>
  <li>Layout em Grid</li>
  <li>Efeitos de Hover</li>
</ul>
<h2>Como Executar</h2>
<ol>
  <li>Clone o repositório.</li>
  <li>Instale as dependências com <code>npm install</code>.</li>
  <li>Execute o compilador LESS para observar alterações e compilar o CSS:</li>
  <pre><code>npm run dev</code></pre>
  <li>Abra o arquivo <code>index.html</code> no navegador para visualizar a página de produtos.</li>
</ol>
<h2>Funcionalidades</h2>
<ul>
  <li>Cabeçalho fixo com navegação</li>
  <li>Grade de produtos responsiva usando CSS Grid</li>
  <li>Variáveis, mixins e mapas de colors reutilizáveis em LESS</li>
  <li>Botões interativos com efeitos de hover</li>
  <li>Imagens de placeholder para fácil personalização</li>
</ul>
<h2>Notas Adicionais</h2>
<p>
  Este projeto foi desenvolvido para praticar recursos do <strong>LESS</strong> e conceitos de design responsivo.
  O layout se adapta automaticamente para desktop, tablet e dispositivos móveis.
</p>
